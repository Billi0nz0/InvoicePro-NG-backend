# Backend API

This is the backend repository for our team project.

## Project Goal

Build the backend authentication system and initial database schema for:

- Users
- Customers
- Invoices
- TOTP/2FA secrets

## Team Workflow

- Do not push directly to main.
- Create a feature branch.
- Open a Pull Request.
- Request review from the Team Lead.
- Merge only after approval.
